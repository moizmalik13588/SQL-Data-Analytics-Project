# 📊 SQL Data Analytics Project

A comprehensive collection of SQL scripts for professional data exploration, analytics, and reporting. This repository is designed to help analysts quickly extract insights, perform segmentation, and build data-driven reports using best practices.

---

## 🚀 Project Overview

This repository contains structured SQL queries categorized by analytical themes:

* **🔍 Database Exploration:** Scripts to audit schemas, check data quality, and understand table relationships.
* **📈 Measures & Metrics:** Calculations for KPIs, conversion rates, and business performance indicators.
* **⏳ Time-Series Analysis:** Trends over time, month-on-month (MoM) growth, and seasonal patterns.
* **🔄 Cumulative Analytics:** Running totals, Year-to-Date (YTD) analysis, and moving averages.
* **👥 Segmentation:** Customer bucketing, RFM analysis, and behavioral clustering.
